# FPGA 引脚对照助手

在浏览器里对照 **核心板 Vivado 引脚** 和 **底板功能**，并可核对 `.xdc` 约束。全部在本地/网页里完成，不经过服务器。

在线地址：https://alen9966.github.io/fpga-pin-helper/

使用说明：https://alen9966.github.io/fpga-pin-helper/使用说明.html

## 用法

1. 打开上面的 GitHub Pages 地址，或本机双击 `启动.bat`。
2. 每次打开页面后，点击「选择两个 Excel」上传自己的核心板 / 底板表；需要试用时可手动点击「加载当前示例」。
3. 「上传约束文件」核对 XDC；行尾 `##[核对]` 批注正确 / 错误 / 多余。

## 对照规则

`IO_L20N_T3_33` ↔ `BANK33_20_N`（`L20N` → `20_N`，`_33` → `BANK33`）。

## 本地运行（可选）

```bat
启动.bat
```

打开 http://127.0.0.1:8765/ 。静态页面也可直接用浏览器打开 `index.html`（加载示例需要通过 http 访问，不能用 `file://`）。
